Design System

Style Guide

This page explains the fonts, colors, and reusable components used in the website.

Fonts

Headings use Poppins because it feels modern and friendly.

Body text uses Inter because it is clean and readable on screens.

Colors

The site uses soft pastel colors like lavender, mint, peach, blush pink, and light blue.

Reusable Components

The site reuses the navigation bar, cards, book covers, buttons, filters, and search result cards.
